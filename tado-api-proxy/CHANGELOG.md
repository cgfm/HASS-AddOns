# Changelog

## 1.1.0

- Initial release as Home Assistant add-on
- Based on tado-api-proxy v1.1.0 (PocketBase backend)
- Web UI accessible via Home Assistant sidebar (Ingress)
- Multi-account support with automatic load balancing
- OAuth2 Device Code Flow for tado authentication (no headless browser needed)
- Official tado API authorization for reduced ban risk
- Support for amd64 and aarch64 architectures
- English and German translations

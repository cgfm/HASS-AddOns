# Tado API Proxy Add-on for Home Assistant

Bypass tado API rate limits with automatic token management, multi-account
support, and a full web UI – all integrated into Home Assistant.

Based on [tado-api-proxy](https://github.com/s1adem4n/tado-api-proxy) v1.1.0.

## Features

- Web UI accessible from the Home Assistant sidebar
- Multiple tado account support with automatic load balancing
- OAuth2 Device Code Flow – authorize in your browser, no passwords stored
- Official tado API authorization for reduced ban risk
- Protected access with optional proxy tokens
- Request statistics and token monitoring
- Supports amd64 and aarch64

## Quick start

1. Install the add-on
2. Set your admin email and password in the configuration
3. Start the add-on
4. Open "Tado API Proxy" from the sidebar
5. Add your tado accounts via the Web UI

For detailed instructions, see the **Documentation** tab in the add-on page.
